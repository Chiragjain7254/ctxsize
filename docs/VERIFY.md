# Check what each agent loads, in 5 minutes

ctxsize never runs an agent. It predicts what each one loads from the agent's official docs.
That is only worth anything if the prediction is right, so this page lets you check it.

[`examples/secret-word/`](../examples/secret-word) is a small project where every instruction
file holds one secret fruit word. Open an agent there and ask which fruits it knows. The fruits it
names are the files it really loaded. The table below shows what ctxsize predicts for each agent.

## Steps

1. Copy `examples/secret-word` outside any other repository and run `git init` in the copy.
2. Run `npx @chiragjain7254/ctxsize --all` there to see the prediction.
3. Open one agent in a NEW session in that folder (Aider: `aider --read CONVENTIONS.md`).
4. Ask exactly:

   > Without reading any files or running any tools, list every secret fruit word you already know from this project's instruction files.

5. Compare its answer with the table. Startup fruits should be named. On-demand fruits and the
   "should NOT know" fruits should not.
6. Repeat in a new session for each agent. Never reuse a session; it may have read files already.

## Found a mismatch?

If an agent knows a fruit the table says it should not, or misses one it should have, ctxsize is
wrong or the agent changed. [Open an issue](https://github.com/Chiragjain7254/ctxsize/issues/new?template=agent-behavior-changed.yml)
with the agent, its version, the fruits it named and a link to its docs. See
[CONTRIBUTING.md](../CONTRIBUTING.md#add-or-update-an-agent) for how to fix the profile.
